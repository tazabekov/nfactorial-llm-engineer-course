# MCP-сервер Chocolife

Ищет скидки и купоны в каталоге chocolife.me и отдаёт их агенту через MCP.

**Инструмент:** `search_deals(category="рестораны", city="Алматы", limit=8) -> DealsResult`

**Транспорт:** stdio. Сервер запускается агентом как дочерний процесс, вручную
запускать не нужно.

**Ручной запуск для отладки:**

    .venv/bin/python mcp_servers/chocolife/server.py

**Офлайн-режим** (отдаёт сохранённую страницу вместо браузера, полезно для отладки
агента без сети):

    AVATAR_AGENT_OFFLINE=1 .venv/bin/python mcp_servers/chocolife/server.py

**Зависимости:** Chromium ставится командой `.venv/bin/playwright install chromium`.

**Кэш:** результаты живут 24 часа в `cache/`. Удалите файлы `chocolife-*.json`,
чтобы принудительно перечитать сайт.

**Почему CATALOG_URL — это главная страница, а не `/restorany-kafe-i-bary/`:**
эмпирически (проверено вручную через Playwright и через встроенный в SSR-страницу
Angular TransferState с ответом API, `items_count`) у Chocolife узкая категория
«Рестораны, кафе и бары» почти всегда отдаёт 0–2 живых предложения — это
реальные, а не заглушечные данные, просто сейчас в Алматы мало активных акций
на рестораны. Более узкие подкатегории (`/catalog/na-shashlyki/`,
`/catalog/korporativy/`, `/catalog/restorany-s-parkovkoy/` и т.д.) при этом не
фильтруют по теме вообще — они отдают один и тот же общий список «популярного
сейчас» (караоке, spa, детские парки), что легко проверить: наборы карточек
для разных подкатегорий совпадают. Единственная страница, где каталог
гарантированно не пуст — главная (`https://chocolife.me/`, витрина текущих
акций по всему городу). Поэтому вживую сервер ходит именно туда; `category` и
`city` в сигнатуре инструмента оставлены для совместимости интерфейса с
2GIS и на случай, если фильтрация по категориям у Chocolife заработает.
Из этого следует важное для Task 7: результаты `search_deals` — это
«актуальные акции по городу», а не гарантированно рестораны; в ответе может
попасться, например, спа или караоке.

**Разметка карточки:** Angular-компонент `<cl-deal>`, внутри которого лежит
`<div class="deal">` с классами `deal__title`, `deal__desc` (первый `span` —
название заведения, второй — «· N покупок»), `deal__price` (текст вида
«от 500 ₸» — это стартовая цена **со скидкой**, исходная цена до скидки в
каталоге не показывается вообще, поэтому `original_price` у Chocolife всегда
`None`) и `deal__percent` (текст вида «-30%» или «до -40%»).

**Если парсер сломался:** обновите фикстуру и поправьте селекторы в
`parser.py` под неё:

    .venv/bin/python tools/capture_fixture.py "https://chocolife.me/" chocolife_deals.html "cl-deal"

После съёмки откройте файл и убедитесь, что карточки `div.deal` всё ещё
содержат классы `deal__title`, `deal__desc`, `deal__price`, `deal__percent`
— если Chocolife их переименовал, поправьте селекторы в `parser.py`.
