# 🎬 Киноагент (Movie Agent)

Интеллектуальный помощник по фильмам на основе LangChain и OpenAI, который может искать фильмы, сравнивать их, находить фильмы по актёрам и давать персонализированные рекомендации.

> 🎯 **Выбранный вариант реализации:** **Вариант 1 — Облачная модель + LangChain** (коэффициент ×1.0). Используются `ChatOpenAI` (gpt-4o-mini), `create_openai_functions_agent`, `AgentExecutor` и `ConversationSummaryBufferMemory` согласно стеку Варианта 1 из задания.

## 🌟 Возможности

- **Локальная база данных**: 1000+ фильмов хранятся локально для мгновенных результатов
- **Резервный API**: Автоматически запрашивает OMDb API для фильмов, отсутствующих в локальной базе
- **Память разговора**: Запоминает контекст и предпочтения на протяжении всей беседы
- **Мульти-инструментальная оркестрация**: Интеллектуально комбинирует несколько инструментов для ответа на сложные запросы
- **Многоязычная поддержка**: Работает с запросами на английском, русском и других языках

## 🚀 Быстрый старт

### Требования

- **Python 3.13.x** — версия зафиксирована заданием. Python 3.14+ **несовместим** с зафиксированными версиями LangChain/Pydantic и упадёт уже на импорте (`'function' object is not subscriptable`).
- API ключ OpenAI
- API ключ OMDb — требуется заданием; также используется как резервный источник для фильмов вне локального Top 1000.

### Установка

1. **Клонируйте репозиторий** (или перейдите в директорию проекта)

```bash
cd movie-agent
```

2. **Создайте и активируйте виртуальное окружение**

```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. **Установите зависимости**

```bash
pip install -r requirements.txt
```

4. **Настройте переменные окружения**

Создайте файл `.env` в корне проекта:

```env
OPENAI_API_KEY=ваш_openai_api_ключ_здесь
OMDB_API_KEY=ваш_omdb_api_ключ_здесь
```

Где получить API ключи:
- OpenAI API: https://platform.openai.com/api-keys
- OMDb API: https://www.omdbapi.com/apikey.aspx (бесплатный тариф — 1000 запросов в день)

### Запуск агента

Агент поддерживает несколько режимов работы:

**Вариант 1: Интерактивное меню** (По умолчанию)

```bash
python agent.py
```

Это покажет меню, где вы можете выбрать между:
- Интерактивный режим чата
- Запуск предопределённых примеров
- Выход

**Вариант 2: Интерактивный режим чата**

```bash
python agent.py chat
# или
python agent.py interactive
# или
python agent.py i
```

Запускает интерактивную сессию чата, где вы можете непрерывно задавать вопросы о фильмах. Возможности:
- Персонализированный опыт - спрашивает ваше имя и использует его на протяжении сессии
- Естественный разговор с памятью
- Работает с английским и русским языками
- Чистый вывод (показывает только финальные ответы, без промежуточных шагов)
- Введите `exit` или `quit` для завершения сессии
- Введите `clear` для сброса памяти разговора

**Вариант 3: Запуск примеров**

```bash
python agent.py examples
# или
python agent.py demo
# или
python agent.py e
```

Запускает 6 предопределённых примеров (3 на английском, 3 на русском), демонстрирующих возможности агента.

**Пример интерактивного чата:**

```
What's your name? / Как вас зовут? Гиззат

👋 Nice to meet you, Гиззат! / Приятно познакомиться, Гиззат!

👤 Гиззат: Какой рейтинг у Inception?
🤖 Agent: Рейтинг **Inception** - **8.8/10** на IMDb.

👤 Гиззат: Сравни его с Matrix
🤖 Agent: Inception имеет более высокий рейтинг (8.8 против 8.7)...

👤 Гиззат: выход
👋 Goodbye, Гиззат! See you next time!
```

**Вариант 4: Программное использование**

Вы также можете импортировать и использовать агента в своём коде:

## 🛠️ Доступные инструменты

Агент имеет доступ к 6 специализированным инструментам:

### 1. `search_movie(query: str)`
Поиск фильмов по названию. Сначала проверяет локальную базу, затем OMDb API.

**Примеры:**
```
"Найди фильмы про Бэтмена"
"Find movies about Batman"
```

### 2. `get_movie_details(title: str)`
Получить подробную информацию о конкретном фильме, включая сюжет, актёров, рейтинги и т.д.

**Примеры:**
```
"Расскажи про фильм Inception"
"Какой рейтинг у Matrix?"
"Tell me about The Dark Knight"
```

### 3. `compare_movies(movie1_title: str, movie2_title: str)`
Сравнить два фильма на основе их рейтингов IMDb и жанров.

**Примеры:**
```
"Сравни Inception и Matrix"
"Compare Interstellar and Arrival"
"Что лучше: Интерстеллар или Прибытие?"
```

### 4. `search_movies_by_actor(actor_name: str)`
Найти все фильмы с участием конкретного актёра, отсортированные по рейтингу.

**Примеры:**
```
"Найди фильмы с Леонардо ДиКаприо"
"Find movies with Tom Hanks"
"Покажи фильмы с Томом Хэнксом и их рейтинги"
```

### 5. `get_top_movies_by_genre(genre: str, limit: int)`
Получить лучшие фильмы в определённом жанре.

**Примеры:**
```
"Покажи лучшие триллеры"
"Show me the best comedies"
"Какие топ-5 комедий?"
```

### 6. `recommend_movie_by_genre(genre1: str, genre2: str)`
Сравнить два жанра и порекомендовать лучший фильм на вечер.

**Примеры:**
```
"Какой фильм лучше для вечера: комедия или триллер?"
"Should I watch an action or drama tonight?"
"Что посмотреть: боевик или драму?"
```

## 🧪 Тестирование различных функций

### Тест 1: Базовая функциональность

Проверка способности агента искать и получать информацию о фильмах.

#### Тест 1.1: Детали фильма (Локальная база)
```
"Расскажи про фильм Inception"
"Tell me about Inception"
```
**Ожидаемое поведение:** 
- Использует инструмент `get_movie_details`
- Возвращает информацию из локальной базы (мгновенно)
- Показывает рейтинг, жанр, режиссёра, сюжет, актёров

#### Тест 1.2: Рейтинг фильма
```
"Какой рейтинг у Matrix?"
"What's the rating of The Matrix?"
```
**Ожидаемое поведение:**
- Использует инструмент `get_movie_details`
- Возвращает рейтинг IMDb: 8.7/10
- Источник: Локальная база данных

#### Тест 1.3: Поиск фильмов
```
"Найди фильмы про Бэтмена"
"Find movies about Batman"
```
**Ожидаемое поведение:**
- Использует инструмент `search_movie`
- Если в локальной базе: возвращает мгновенно
- Если нет в локальной базе: запрашивает OMDb API
- Возвращает список фильмов про Бэтмена

---

### Тест 2: Память разговора

Проверка способности агента запоминать контекст и предпочтения пользователя.

#### Тест 2.1: Запомнить имя пользователя
```
1. "Меня зовут Асель" / "My name is Asel"
2. "Как меня зовут?" / "What's my name?"
```
**Ожидаемое поведение:**
- Агент запоминает имя из истории разговора
- Отвечает: "Вас зовут Асель" (или похоже)

#### Тест 2.2: Запомнить предпочтения
```
1. "Я люблю фильмы Нолана" / "I love Nolan's movies"
2. "Порекомендуй мне фильм" / "Recommend me a movie"
3. (Продолжить разговор с 5+ сообщениями)
4. "Что я люблю?" / "What do I love?"
```
**Ожидаемое поведение:**
- Агент сохраняет предпочтение в памяти разговора
- После множества сообщений всё ещё помнит про "фильмы Нолана"
- Может использовать эту информацию для рекомендаций

#### Тест 2.3: Контекстное продолжение
```
1. "Сравни Inception и Matrix"
2. "Какой из них вышел раньше?"
3. "Кто его снял?"
```
**Ожидаемое поведение:**
- Понимает, что "какой из них" относится к предыдущим фильмам
- Понимает, что "его" относится к фильму из контекста
- Нет необходимости повторять названия фильмов

---

### Тест 3: Мультиинструментальные вызовы

Проверка способности агента оркестрировать несколько инструментов для сложных запросов.

#### Тест 3.1: Сравнить два фильма
```
"Сравни Inception и Matrix"
"Compare Inception and The Matrix"
```
**Ожидаемое поведение:**
- Вызывает инструмент `compare_movies` с обоими названиями
- Инструмент внутренне получает данные для обоих фильмов
- Возвращает сравнение:
  - Inception: 8.8/10 (Action, Adventure, Sci-Fi)
  - The Matrix: 8.7/10 (Action, Sci-Fi)
  - Общие жанры: Action, Sci-Fi
  - Более высокий рейтинг: Inception

#### Тест 3.2: Поиск актёра + Детали
```
"Найди фильмы с Леонардо ДиКаприо и покажи детали самого рейтингового"
"Find Leonardo DiCaprio movies and show details of the highest rated one"
```
**Ожидаемое поведение:**
1. Вызывает `search_movies_by_actor("Leonardo DiCaprio")`
2. Определяет фильм с самым высоким рейтингом: Inception (8.8/10)
3. Вызывает `get_movie_details("Inception")`
4. Возвращает полную информацию об Inception

#### Тест 3.3: Сравнение жанров + Рекомендация
```
"Какой фильм лучше для вечера: комедия или триллер?"
"Should I watch a comedy or thriller tonight?"
```
**Ожидаемое поведение:**
1. Может вызвать `get_top_movies_by_genre("Comedy")`
2. Может вызвать `get_top_movies_by_genre("Thriller")`
3. Вызывает `recommend_movie_by_genre("Comedy", "Thriller")`
4. Возвращает сравнение и рекомендацию с обоснованием

---

### Тест 4: Продвинутые сценарии

#### Тест 4.1: Сложный многошаговый запрос
```
"Найди все фильмы Кристофера Нолана, сравни два лучших и скажи, какой лучше для любителя научной фантастики"
"Find all Christopher Nolan movies, compare the top two, and tell me which is better for sci-fi lovers"
```
**Ожидаемое поведение:**
- Ищет фильмы Нолана (может использовать поиск по режиссёру или множественный поиск фильмов)
- Определяет топ-2 по рейтингу
- Сравнивает их
- Даёт персонализированную рекомендацию на основе предпочтения научной фантастики

#### Тест 4.2: Резервный вызов API
```
"Расскажи про Oppenheimer"  (фильм 2023 года, отсутствует в локальной базе)
```
**Ожидаемое поведение:**
- Сначала ищет в локальной базе
- Не найдено в локальной базе
- Переключается на OMDb API
- Возвращает информацию из API

#### Тест 4.3: Актёр + Фильтр по жанру
```
"Найди боевики с Томом Крузом и покажи их рейтинги"
"Find action movies with Tom Cruise and show their ratings"
```
**Ожидаемое поведение:**
- Вызывает `search_movies_by_actor("Tom Cruise")`
- Фильтрует результаты по жанру Action
- Возвращает список с рейтингами

## 🔧 Устранение неполадок

### Проблема: "ModuleNotFoundError: No module named 'langchain'"
**Решение:** Убедитесь, что активировали виртуальное окружение и установили зависимости:
```bash
source venv/bin/activate
pip install -r requirements.txt
```

### Проблема: "Error: OPENAI_API_KEY not found"
**Решение:** Создайте файл `.env` в корне проекта с вашим API ключом:
```env
OPENAI_API_KEY=sk-...ваш-ключ-здесь...
```

### Проблема: "401 Unauthorized" для OMDb API
**Решение:** 
- Получите бесплатный API ключ на https://www.omdbapi.com/apikey.aspx
- Добавьте его в файл `.env` как `OMDB_API_KEY=ваш-ключ`
- Примечание: Агент отлично работает с 1000 фильмов из локальной базы без OMDb API

### Проблема: Предупреждения о deprecation памяти
**Решение:** Это предупреждение о будущих версиях LangChain. Функциональность всё ещё работает корректно. Предупреждение можно игнорировать пока.
