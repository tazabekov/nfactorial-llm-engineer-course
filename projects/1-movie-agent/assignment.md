# Project 01 — AI Movie Agent

## 📋 Описание проекта

Создать AI-агента **«Киноманьяк»**, который является экспертом по фильмам и может отвечать на любые вопросы о кино.

> **Дедлайн:** 3 мая 23:50 по времени Астаны

> **Формат сдачи:** ZIP-архив или один файл (если проект состоит из одного файла) через Google Classroom

> **Максимальный балл:** 100

---

## 🎯 Варианты реализации

Вы можете выбрать **один из трех вариантов** реализации проекта. Каждый вариант оценивается по-разному:

### Вариант 1: Облачная модель + LangChain *(коэффициент 1.0)*

**Стек:**

- Облачная LLM (OpenAI GPT-5, Gemini, Claude и т.д.)
- Готовые инструменты LangChain для агентов и памяти
- `create_openai_functions_agent` или аналоги

**Что использовать:**

- `ConversationBufferMemory` или `ConversationSummaryBufferMemory`
- `@tool` декоратор для создания инструментов
- `AgentExecutor` для запуска агента

**Оценка:** Ваш балл × 1.0 (максимум 100)

> 💡 **Для кого:** Идеально для начинающих и тех, кто хочет быстро разобраться с концепциями

### Вариант 2: Локальная модель + LangChain *(коэффициент 1.1)*

**Стек:**

- Локальная LLM через Ollama (например, `qwen2.5:8b`, `llama3.2`)
- Готовые инструменты LangChain для агентов и памяти
- Интеграция `langchain-ollama`

**Что использовать:**

- Ollama для запуска модели локально
- Те же инструменты LangChain, что и в варианте 1
- Настройка для работы с локальными моделями

**Требования:**

- Установить Ollama
- Скачать модель с поддержкой function calling
- Настроить интеграцию с LangChain

**Оценка:** Ваш балл × 1.1 (максимум 100)

**Пример:** если вы набрали 80 баллов, итоговая оценка = 80 × 1.1 = 88 баллов

> 💡 **Для кого:** Для тех, кто хочет работать с локальными моделями и не зависеть от API

### Вариант 3: Самописный фреймворк + Облачная модель *(коэффициент 1.2)*

**Стек:**

- Облачная LLM (OpenAI, Gemini, Claude и т.д.)
- **Самостоятельная реализация** памяти и tool calling
- БЕЗ готовых инструментов LangChain для агентов

**Что реализовать самостоятельно:**

- ✅ Система управления памятью (хранение истории диалога)
- ✅ Парсинг tool calling из ответов LLM
- ✅ Цикл агента (agent loop) с reasoning
- ✅ Обработка ошибок и повторные попытки

**Что можно использовать:**

- Прямые API вызовы к LLM (например, OpenAI API)
- Базовые библиотеки Python (requests, json и т.д.)
- Структуры данных для хранения памяти

**Что НЕЛЬЗЯ использовать:**

- `AgentExecutor`
- `create_openai_functions_agent`
- Готовые классы памяти LangChain

**Оценка:** Ваш балл × 1.2 (максимум 100)

**Пример:** если вы набрали 80 баллов, итоговая оценка = 80 × 1.2 = 96 баллов

> 💡 **Для кого:** Для продвинутых студентов, которые хотят глубоко понять работу агентных систем

### 2️⃣ Memory (Память) — Урок 4

#### Типы памяти из урока

**ConversationBufferMemory** *(простой вариант)*

- Хранит всю историю сообщений
- Простая в использовании
- Ограничена размером контекста

**ConversationSummaryBufferMemory** *(продвинутый вариант)*

- Суммаризирует старые сообщения
- Сохраняет последние сообщения целиком
- Работает с длинными диалогами
- Требует передачи LLM для суммаризации

#### Ваша задача

Выбрать тип памяти и настроить её так, чтобы агент:

- ✅ Запоминал **имя** пользователя
- ✅ Запоминал **предпочтения** (любимые фильмы, жанры)
- ✅ Мог использовать эту информацию в будущих ответах

#### Пример настройки

```python
from langchain.memory import ConversationBufferMemory
# или
from langchain.memory import ConversationSummaryBufferMemory

# Настройте память
memory = ...  # Ваша реализация
```

**Параметры для изучения:**

- `max_token_limit` — лимит токенов
- `memory_key` — ключ для промпта
- `return_messages` — формат возврата

> 💡 **Для варианта 3:** Реализуйте свою систему хранения истории диалога (например, список словарей с ролями и сообщениями)

### 3️⃣ Agents (Агенты) — Урок 4

#### Что вы знаете из урока

- Как создавать агентов с `create_openai_functions_agent`
- Что такое `AgentExecutor`
- Как работает agent loop

#### Ваша задача

Создать агента который:

1. Использует ваши tools
2. Имеет память
3. Может вызывать несколько инструментов последовательно

#### Пример реализации *(для вариантов 1 и 2)*

```python
from langchain_openai import ChatOpenAI
from langchain.agents import create_openai_functions_agent, AgentExecutor

# 1. Создайте LLM
llm = ChatOpenAI(...)

# 2. Создайте агента
agent = create_openai_functions_agent(
    llm=llm,
    tools=[...],  # Ваши tools
    prompt=...    # Ваш промпт
)

# 3. Создайте executor
agent_executor = AgentExecutor(
    agent=agent,
    tools=[...],
    memory=...,
    verbose=True  # ВАЖНО для reasoning
)
```

### 4️⃣ Prompts (Промпты) — Урок 3

#### Техники промптинга из урока

- **Few-shot prompting** — примеры в промпте
- **Role-based prompts** — роль агента
- **Chain-of-thought** — размышление вслух

#### Ваша задача

Создать системный промпт который:

- ✅ Определяет **роль** агента (кто он)
- ✅ Описывает **инструменты**, которые доступны
- ✅ Объясняет **как работать с памятью**
- ✅ Содержит **примеры** (few-shot)

#### Пример структуры

```python
from langchain.prompts import ChatPromptTemplate, MessagesPlaceholder

prompt = ChatPromptTemplate.from_messages([
    ("system", "Твой системный промпт здесь..."),
    MessagesPlaceholder(variable_name="chat_history"),  # Для памяти
    ("human", "{input}"),
    MessagesPlaceholder(variable_name="agent_scratchpad")  # Для агента
])
```

**Элементы хорошего промпта:**

1. **Роль:** "Ты — эксперт по кино..."
2. **Инструкции:** "Используй инструменты для..."
3. **Примеры:** "Пример: если пользователь спросил X, сделай Y"
4. **Ограничения:** "НЕ выдумывай факты, используй только API"

```
→ Найти топ комедии → Найти топ триллера → Дать рекомендацию
```
